# ⚡ Quick Start Guide

Get up and running in 5 minutes!

## 🎯 What You Need

1. **Gemini API Key** - [Get it FREE here](https://ai.google.dev/) 🔑
2. **Node.js 18+** installed on your machine

## 📦 Installation (2 minutes)

### Step 1: Install Backend Dependencies
\`\`\`bash
cd backend
npm install
\`\`\`

### Step 2: Install Frontend Dependencies
\`\`\`bash
cd ../frontend
npm install
\`\`\`

## 🔑 Configure API Key (1 minute)

\`\`\`bash
cd ../backend
cp .env.example .env
\`\`\`

Edit `backend/.env` and add your API key:
\`\`\`
GEMINI_API_KEY=paste_your_api_key_here
\`\`\`

## 🚀 Run the Application (30 seconds)

**Terminal 1 - Backend:**
\`\`\`bash
cd backend
npm run dev
\`\`\`

**Terminal 2 - Frontend:**
\`\`\`bash
cd frontend
npm start
\`\`\`

## 🌐 Access

Open browser to: **http://localhost:4200**

## ✨ Features to Try

- 💬 Chat with AI
- 🌓 Toggle dark/light theme
- 📝 Ask for code examples
- 📋 Copy code blocks
- 🎨 Markdown formatting
